# Suporte

## Onde pedir ajuda

- **Dúvidas de uso e arquitetura:** GitHub Discussions do repositório.
- **Defeitos reproduzíveis:** template de Bug Report, usando dados sintéticos.
- **Propostas de melhoria:** template de Feature Request.
- **Vulnerabilidades:** siga exclusivamente [SECURITY.md](SECURITY.md).

## Informações úteis

Inclua versão/commit, ambiente, payload sanitizado, resultado esperado, resultado observado e valores decimais exatos. Nunca envie dados de clientes, segredos, chaves ou informações financeiras reais sem autorização formal.

## Escopo de suporte

O suporte cobre o comportamento técnico documentado da engine. Não cobre aconselhamento jurídico, tributário, contábil ou financeiro.
